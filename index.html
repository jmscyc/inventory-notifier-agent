Google Sheet 權限設定與同步教學

💡 為什麼要結合 Google Sheet？

資料不再只存在本地設備，而是直接放在您個人的 Google 雲端！試算表直覺好讀，手機開 Google 試算表 App 就能看；同時還能做為 API 讓 GitHub Actions 24/7 自動排程抓取與回寫！

1

建立 Google 試算表

前往 Google 雲端硬碟建立一個新的試算表，命名為「電商庫存監控雲端資料庫」。

2

貼入 Google Apps Script (GAS) 程式碼

在試算表上方選單點擊「擴充功能」 ➔ 「Apps Script」，將專案中的 GoogleAppsScript_Code.js 內容全部複製並貼上取代原本的程式碼，按下 Ctrl+S 儲存。

3

執行初始化設定

在 Apps Script 上方的函式下拉選單選擇 setupSheets，點擊「執行」。(首次執行請點「審查權限」➔ 選擇您的 Google 帳號 ➔ 「進階」 ➔ 前往專案並允許)。執行後，系統會自動在試算表建立「商品清單」、「系統設定」與「巡檢日誌」三個分頁！

4

部署為網路應用程式 (關鍵權限設定 🔐)

點擊右上角藍色「部署」 ➔ 「新建部署」：

  • 種類選擇：網路應用程式 (Web App)
  • 說明：電商監控 API
  • 執行身分：我 (您的 Google 帳號)
  • 誰可以存取：任何人 (Anyone) (這樣網頁與 GitHub Actions 才能連線)
5

複製網址並填入本後台

複製部署完成產生的 Web App URL (結尾為 /exec)，點擊本網頁右上角的「設定 Google Sheet API」貼上即可完成綁定！

🔒 關於權限安全性的疑慮：

「誰可以存取設為任何人」是 Google Apps Script 標準的公開 API 部署模式。他人並不會獲得您 Google 帳號的權限，也無法查看您的私人檔案，只能透過我們寫好的代碼針對這個特定的監控試算表進行讀寫，非常安全可靠！
